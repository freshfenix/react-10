# React Memoization Lab

Інтерактивний навчальний React-застосунок, що показує, як `useMemo`, `useCallback` і `React.memo` допомагають уникати непотрібних обчислень та рендерів.

## Можливості

- Пошук по набору з 12 000 записів і відображення перших шести результатів.
- Порівняння звичайної фільтрації з фільтрацією, мемоізованою через `useMemo`.
- Лічильники обчислень і рендерів панелей та списків.
- Незалежне оновлення лічильника, щоб побачити, як `React.memo` запобігає повторному рендеру незміненого списку.
- Вибір запису та адаптивний інтерфейс.

## Запуск локально

Потрібні Node.js та npm.

```bash
npm install
npm run dev
```

Відкрийте адресу, показану Vite у терміналі (зазвичай `http://localhost:5173`).

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити локальний сервер розробки |
| `npm run build` | Створити production-збірку в `dist/` |
| `npm run preview` | Переглянути production-збірку локально після `npm run build` |

## Як дослідити мемоізацію

1. Введіть запит, наприклад `React` або `дизайн`, і порівняйте результати та час пошуку в обох панелях.
2. Натисніть **«Оновити стан»**. Лічильники рендерів панелей зростуть, але оптимізований список не має перерендеритися, оскільки його props не змінилися.
3. Виберіть запис. Список перерендериться, щоб відобразити вибраний стан.
4. Змініть пошуковий запит. Фільтрація виконається в обох панелях; `useMemo` перерахує оптимізовані результати, бо змінилася залежність `query`.

Час вимірюється безпосередньо для кожного пошуку; це наочна демонстрація, а не стабільний бенчмарк. Реальні значення залежать від браузера та пристрою.

## Де реалізовано

- `src/App.jsx` — стан пошуку й вибору, а також стабільні обробники на `useCallback`.
- `src/components/MemoizationDemo.jsx` — набір даних, фільтрація, порівняння двох підходів, метрики, `useMemo` та список, обгорнутий у `React.memo`.
- `src/App.css` — стилі інтерфейсу та адаптивне компонування.
- `vite.config.js` — конфігурація Vite з React-плагіном.
